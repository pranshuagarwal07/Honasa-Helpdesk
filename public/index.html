GRN & GIN acks

Enter an ASN number to ack its GRN, or an outbound order code to ack its GIN. You review the payload before anything is sent.

What the code is
  1. FindEnter the ASN number or order code.
  2. ReviewCheck the warnings and the payload built from the WMS.
  3. PushSend the ack to cincout.
  4. VerifyStatus is read back so you know it landed.
